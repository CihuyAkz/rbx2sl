Upload hasil ke GitHub
OPTIONAL

Set repo tujuan. Sesudah commit upload, GitHub Actions yang memakai event push akan berjalan otomatis. Masukkan nama workflow jika ingin memicu build khusus lewat workflow_dispatch. URL HTTPS raw juga bisa dibuka langsung, tetapi file .lua adalah kode sumber dan tidak dieksekusi oleh browser.

Keamanan: token hanya dipakai selama halaman ini terbuka dan tidak disimpan ke localStorage. Gunakan token fine-grained yang dibatasi ke satu repo. Izin minimum upload: Contents: Read and write. Untuk trigger workflow khusus, tambahkan Actions: Write. Jangan bagikan token ke siapa pun.

Runner Script · jalankan file Lua yang sudah di-upload

Salin script ini ke Roblox Studio sebagai Script di ServerScriptService. Aktifkan Allow HTTP Requests di Game Settings → Security, dan aktifkan ServerScriptService.LoadStringEnabled di Studio. Loader ini memerlukan repository publik, menjalankan kode dari URL GitHub, dan tidak menyimpan token GitHub. Jalankan hanya kode yang kamu percaya.
